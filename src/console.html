OPERATOR CONSOLE & REAL-WORLD SCENARIOS

1. Real-World Developer Scenarios Solved

  • Secret & Sensitive Path Intrusion (F2 / 'B'): Alerts in red if an autonomous agent (Copilot, Hermes, Antigravity) attempts to read/write .env, id_rsa, or credentials.
  • Unified Diff Forensics (F3 / 'D'): Inspect exact colorized git additions (+) and deletions (-) generated by agents before approving or committing.
  • Zero-Token Interception Audit (F5): Track why requests were intercepted, model targets, inference latency, and external API token savings.
  • Cryptographic Ledger Proof ('V'): Run headless SHA-256 and Ed25519 verification over the entire blockchain history to guarantee zero log tampering.
  • Runtime Sandboxing: Type :policy copilot strict to clamp down permissions in memory without server downtime.

2. Keyboard Shortcuts

  • j / k or ↓ / ↑: Navigate through events.
  • /: Focus search filter.
  • V: Run cryptographic ledger verification.
  • P: Pause/Resume live SSE stream.
  • D: Switch inspector to Unified Diff tab.
  • B: Quick-filter only Blocked/Alert events.
  • ?: Toggle this help dialog.
  • Esc: Clear filter or close dialogs.
