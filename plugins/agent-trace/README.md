# 🛰️ AgentTrace Antigravity Plugin

Official Antigravity IDE and Agentic Plugin for **AgentTrace** — the local-first cryptographic telemetry gateway, multi-node cluster orchestrator, and living project chronicle for AI coding agents.

---

## 📦 What This Plugin Bundles

1. **Native Rust MCP Server (`agent-trace`)**:
   - Spawns `agent_trace_mcp.exe` over stdio JSON-RPC 2.0.
   - Provides 29 tools for ledger verification, telemetry search, alert acknowledgment, cluster health inspection, workgroup management, and project chronicle logging.

2. **3 Core Agent Skills**:
   - `agent-trace-audit`: Cryptographic verification and telemetry filtering.
   - `agent-trace-cluster`: Distributed cluster deployment, worker diagnostics, and zero-walk bootstrapping.
   - `agent-trace-project-book`: Autonomous chronicle recording into the living Studio Project Book.

3. **Autonomous Governance Rules (`rules/AGENTS.md`)**:
   - Enforces Work-First UI ergonomics (high density, scenario toolbars, keyboard shortcuts).
   - Enforces Single Responsibility Principle (SRP) and feature-per-file architecture.
   - Enforces zero-token local cluster delegation (PC-1 `qwen3.8:27b` and PC-2 `deepseek-r1:1.5b`).

---

## 🚀 Activation

Once installed, the plugin activates whenever Antigravity runs. All MCP tools become directly available in chat and subagent toolsets.
